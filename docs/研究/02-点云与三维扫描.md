## 结论速览

1. **本项目最关键的分野，答案是"上半段"：公开 LiDAR 能拿到屋面（顶面轮廓 + 标高），拿不到立面。** 英国环境署（Environment Agency）的 **National LIDAR Programme** 是 1 m、全英格兰覆盖、OGL 免费可商用；其 **点云并未剔除建筑点**（官方只做了 ground / low / medium / high vegetation 四类自动分类，**分类体系里没有"建筑"类**），且官方 **First Return DSM（首回波 DSM）** 的说明原文直接写明可用于 **"production of building outlines"**。所以**屋面点云与轮廓是可得的**，而看台竖直立面、悬挑屋盖下弦、座席阶梯、室内则完全拿不到。

2. **公开渠道没有任何"球场级"点云。** 老特拉福德本身**没有公开的激光扫描/点云成果**（学术、结构检测、历史建筑记录都没有）。2026-04 确有布里斯托大学团队用无人机飞越过球场，但那是**探雷演示**，不是球场三维扫描；2024-01 球场出现过测量员与经纬仪，媒体报道明确说是**为满足环保法规而更新图纸**，也不是点云。

3. **现成三维模型能买到，但展览授权是坑。** Sketchfab 上确有 2 个可下载的 Old Trafford 模型（其中一个 **CC BY**，约 14.5 万面；另一个免费标准授权，约 23 万面）；RenderHub 的 **$59.99** 版本是市面上最完整的商业模型之一（约 44 万面），但其授权是 **Extended Use License (IP Restricted) + Editorial Use Only**——**公开模型展览属于高风险用途，买前必须逐一确认**。

4. **自采在英国是"能做但必须合规"的事。** 球场距曼彻斯特机场约 12 km，**不在机场 FRZ 的一般范围内**（曼彻斯特 FRZ ≈ 2.5 NM 半径 + 跑道两端 5 km×1 km 的 RPZ，地面至标高以上 2000 ft，24 小时），但**英国曾为老特拉福德单独发布过飞行限制法规**（UKSI 2019/635，标题即 "(Old Trafford, Manchester)"），且**比赛日 7.4 万人聚集属于绝对禁飞情形**。任何飞行前必须查 **UK AIP ENR 5.1 + 当日 PIB 简报 + 俱乐部书面许可**。

5. **地面摄影测量是最现实的自采路线。** 球场周边多为公共道路与人行道，地面拍摄（三脚架 + 高重叠）在法律上比无人机简单得多（不涉及空域），精度 5–20 mm 量级，足以支撑展览模型的立面与材质；**屋盖顶面仍需无人机**，或者退一步接受"公开 LiDAR 屋面 + 自采立面"的混合方案。

#### ⭐ 关键问题直答：城市级 LiDAR 能拿到屋顶/看台结构吗？

> 提问原文："城市级 LiDAR 通常只保留地面点、剔除建筑与植被，那么屋顶/看台结构能否从中得到？"

**答：能拿到屋面，且证据充分；前提是分清三个层次。**

| 层次 | 结论 | 证据 |
|---|---|---|
| 点云里**有没有**建筑点 | ✅ **有** | 官方对 LIDAR Point Cloud 的定义只做了 **ground / low / medium / high vegetation** 四类自动分类，**没有 building 类，也没有做建筑剔除**。建筑回波被留在点云中（落在未分类类），需要自行分割。→ **"城市级 LiDAR 只保留地面点"这个前提本身不成立**（至少对英国环境署的产品不成立） |
| DSM 里**有没有**屋面 | ✅ **有** | 官方原文："DSM is created from the last or only LIDAR pulse returned to the sensor and contains **all ground and surface objects**" |
| 能不能**提取建筑轮廓** | ✅ **官方明说可以** | First Return DSM 说明原文："It can often be used in canopy height modelling and **production of building outlines**" |

**因此对老特拉福德，公开 LiDAR 能给到：**

| 部位 | 可得性 | 量化预期 |
|---|---|---|
| 四座看台的**屋盖顶面标高** | ✅ 可得 | ±15 cm RMSE 量级 |
| 屋面**外轮廓大形**（方形/弧形转折） | ✅ 可得 | 1 m 网格可辨大形；首回波 DSM 更贴形 |
| 四座看台**相对高度层级** | ✅ 可得 | DSM − DTM 相减即可 |
| 场地、跑道、周边道路地面 | ✅ 可得 | ±15 cm |
| 悬挑屋盖的**下弦/桁架/杆件** | ❌ 不可得 | 近天底扫描的固有盲区 |
| 看台**竖直立面**、幕墙分格 | ❌ 不可得 | 竖直面回波极少 |
| **座席阶梯排距、台阶数** | ❌ 不可得 | 被屋盖遮挡 + 1 m 网格不足 |
| **室内**（走廊、包厢、更衣室） | ❌ 不可得 | 城市级 LiDAR 不测室内 |

**一句话：处于"能拿到建筑外观"与"只能拿到地面高程"之间的上半段——屋面轮廓有了，立面一片空白。要补立面只能自采。**

#### 关于 25 cm / 50 cm 档位（已核实，结论偏负面）

- 用 CKAN 全库检索 `title:lidar 50cm` → **18 个数据集**，排名第一的是 **"LiDAR for Outer Hebrides 2019 - 50cm DTM"**（SEPA 委托 **Bluesky International Ltd.** 采集，点云 **4 points/m²**，OGL，约 1705 km²，其中含 25 cm 更高分辨率区域）。✅ 实测
- 检索 `title:lidar 25cm` → **16 个数据集**，排名第一的是 **"Historic LIDAR Archive"**（**Natural Resources Wales**，号称提供 **25 cm / 50 cm / 1 m / 2 m** 四档，覆盖约 70% 威尔士，OGL）。原文："Up to 100,000 measurements per second are made of the ground, allowing highly detailed terrain models to be generated at spatial resolutions of between **25cm and 2 metres**"。✅ 实测
- **结论：25/50 cm 档位在英格兰不是全国性覆盖，而是按项目采购的零散区域（海岸带、洪水区、城市试点）。大曼彻斯特是否有 25/50 cm 档，本环境无法完成门户点击级核实 → 标注「未验证」，须用索引目录反查。**
- 对比参考：**苏格兰**正在做的 Scottish Land LiDAR Programme 由 **Bluesky International Limited** 采集，**10 points/m²**、2025–2027 年（https://ckan.publishing.service.gov.uk/dataset/scottish-land-lidar-programme-dsm）——说明"更高点密度"在英国已是可采购能力，只是没有免费铺到英格兰城市。

### 1. 曼彻斯特机场 UAS 限制区（NATS 官方规则，已实测原文）

来源：https://nats-uk.ead-it.com/cms-nats/opencms/en/uas-restriction-zones/ （✅ HTTP 200，正文完整读到）

- 永久性限制公布于 **UK AIP 第 ENR 5.1 节**（Prohibited, Restricted and Danger Areas），含机场周边的 **Flight Restriction Zone (FRZ)** 及其他区域限制。
- **FRZ 构成**：机场既有**机场交通区（ATZ）** + （如适用）**跑道保护区（RPZ）**。RPZ 形状为 **5 km × 1 km**，自跑道两端 threshold 起算。**两个区域均向上延伸至机场标高以上 2,000 ft。**
- 原文："**It is illegal to fly any drone at any time within these restricted zones unless you have permission from air traffic control at the airport** or, if air traffic control is not operational, from the airport itself."
- FRZ 与 RPZ **无论地图工具如何绘制，都是相邻连通的**（不要依赖第三方地图的视觉间隙）。
- 数字数据集：NATS 提供 **AIXM 5.1** 格式，另有 **KMZ**；随 UK AIP AIRAC 周期更新。
- **临时限制**通过 **NOTAM** 或 **AIP Supplement** 发布；**飞行前必须做 Pre-flight Information Briefing (PIB)**。

| 路线 | 设备 | 可达精度 | 适用部位 | 法律难度 | 成本量级 |

### 6. 推荐组合（针对"展览用 + 较高精度"）

```
EA LiDAR 1m DSM(首回波) / DTM ──┐
OS MasterMap / NGD 轮廓 ────────┼──> 全局基准（平面位置 + 屋面标高 + 看台高度层级）
                                ┘
地面摄影测量 + 局部 TLS ────────────> 【主战场】看台立面几何与材质纹理
        （公共可达视点，环绕四座看台）
                                │
（如获许可）无人机环绕摄影测量 ─────> 屋盖顶面、檐口、场地全景补充
                                │
        配准 / 合并（CloudCompare）→ 展览模型
```

**关键做法：** 用 EA LiDAR 的屋面标高**约束**摄影测量成果的绝对尺度与水平位置，避免 SfM 的尺度漂移与坐标系错位——这是把"免费的低精度全局"和"自采的高精度局部"缝合起来的标准手法。

### 7. 摄影测量照片数量与重叠率（工程经验值）

> ⚠️ 以下为**行业通行经验值**，非引自某一份已实测的官方文档，**请按实测结果微调**。

| 场景 | 重叠率 | 照片量估算 |
|---|---|---|
| 无人机正射（测绘级） | **航向 75–80% / 旁向 60–70%** | 单座看台 300–800 张 |
| SfM 通用最低门槛 | **60% / 60%**，低于此易断链 | — |
| **单座看台环绕（推荐主方案）** | 每层 ≥ 70% 相邻重叠 | **8–16 个机位 × 3 个高度层（檐口 1.5× / 2.5× / 3.5×）× 每层 30–60 张** ≈ **1,000–2,500 张** |
| 四座看台 + 外圈全景 | 同上 | **总计 3,000–8,000 张** |
| 地面补拍（立面细节、材质） | ≥ 80% 重叠，交叉基线 | 每处 100–300 张，总计 500–1,500 张 |

**要点：**
- **多高度层 + 多角度**是拿到"立面 + 檐口 + 屋盖边缘"的关键；单一高度层的环绕会留下大面积空洞。
- **交叉基线**（同一点位横向偏移再拍一组）能显著提升立面几何质量。
- 阴天**漫射光**最利于纹理一致性；避免强烈日照造成的硬阴影与反光。
- 球场的**对称性**是 SfM 的陷阱：重复结构极易误匹配。**每座看台单独重建，最后配准拼合**，比一次跑全场成功率高得多。

## 给建模阶段的三条硬建议

1. **不要把时间花在"找球场级点云"上——它不存在。** 立刻把预算与精力切到 **地面摄影测量自采**（合法、可控、精度最高）+ **EA LiDAR 提供全局基准**的组合上。
2. **免费数据的正确用法是"定标尺"，不是"当模型"。** 用 1 m 首回波 DSM 的屋面标高与轮廓去约束自采成果的绝对位置与尺度；模型的美观与细节全部来自自采。
3. **授权风险最高的两个来源要单独把关**：RenderHub 版模型是 **Editorial Use Only**，Google/Bing/Esri 影像**禁止衍生**。展览是公开商业场景，这两条踩了会很难看。
