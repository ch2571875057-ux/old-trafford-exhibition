每张卡需要搜集/确认的信息：
1. 球员比赛照（竖构图、人物居中偏上，作为正面背景）
2. 球员号码（印在右下角红色球衣上）
3. 位置英文缩写（GK/RB/CB/LB/CDM/CM/CAM/RW/LW/CF/ST，左上角）
4. 国籍三位代码（BEL/POR/FRA/ENG/ARG/BRA/CMR/CIV/SVN/NED/MAR，左上角）
5. 背面生涯成就条目（每条一年份 + 一句话）
