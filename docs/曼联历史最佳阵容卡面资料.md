## 一、评选口径与主选阵容

**口径说明**：队史最佳没有官方答案，以下主选阵容综合三类来源交叉印证：

1. 名宿评选汇总（Planet Sport 汇编前曼联球员们的选择，出现频率最高的骨架是
   舒梅切尔 + 92 班后卫线 + 基恩/斯科尔斯中轴 + 神圣三杰）；
2. 球迷社区共识（r/ManchesterUnited、UTDForum 等：门将位置舒梅切尔对范德萨
   一边倒，右后卫加里·内维尔近乎全票）；
3. The Athletic「曼联队史百大球星」系列排名（2026 年更新中）。

**主选 XI（4-4-2 · 死忠区视角，进攻方向 +X）**：

```
                    舒梅切尔
   加里·内维尔  费迪南德  维迪奇  埃尔文
   贝斯特  基恩(队长)  斯科尔斯  吉格斯
        博比·查尔顿    丹尼斯·劳
```

选阵逻辑：**神圣三杰**（贝斯特–查尔顿–劳）是慕尼黑空难后 1968 欧冠一代的旗帜，
**三冠王中轴**（舒梅切尔–内维尔–基恩–斯科尔斯–吉格斯）是 1999 三冠王与 13 座
英超王朝的脊梁；费迪南德 + 维迪奇是弗格森时代最稳的中卫组合。落选争议最大的是
C罗、坎通纳、贝克汉姆、鲁尼——全部进备选池（见第五节），后续可做第二套卡面。

**主教练**：亚历克斯·弗格森爵士（备选：马特·巴斯比爵士，两人各代表一个王朝）。

   人形补间走位复用 `switchFormation()` 的补间通道，卡面查找按数据组分流。
3. **卡面渲染**：`fullCardHTML()` 已支持 `coach` 分支（西装图标），教练卡直接可用；
   球员卡复用现有模板，历史球员 `num` 用其标志性号码即可。
4. **照片**：`assets/球员照片/<slug>.jpg`，历史球星照片同样属网络搜集图，
   `statNote` 里保留授权提醒。
5. **展示口径**：抽屉分组标题建议「队史最佳阵容 / ALL-TIME XI」，并在卡面背面
   `statNote` 注明评选为媒体与名宿口径、非官方评选。
