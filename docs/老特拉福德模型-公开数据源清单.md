# 老特拉福德球场模型（展览用）· 公开数据源清单

> 调研对象：Old Trafford, Sir Matt Busby Way, Stretford, Manchester M16 0RA
> 定位：约 53.4631°N, 2.2913°W；OS 国家网格中心约 **SJ 8086 9634**
> 用途：**模型展览**，要求**较高精度**
> 阶段：**只做数据源调研，不建模**
> 调研日期：2026-10-22

---

## 0. 核心结论（先看这七条）

1. **公开渠道不存在老特拉福德的竣工级三维数据。** 点云、BIM、施工图归曼联俱乐部及其设计方所有，不是开放数据。任何声称"免费下载老特拉福德精模"的来源，质量与授权都要打问号。

2. **公开数据能达到的最高精度，是「表面高程精确 + 外部体量近似」。** 英国环境署（Environment Agency）国家 LiDAR 的垂直精度为 **±15 cm RMSE**，DSM 1 m 网格覆盖全英格兰约 99%，点云为 LAZ 格式。它给你**屋面标高、看台顶部轮廓、场地起伏**；但**给不了立面分格、悬挑屋盖上下弦、看台内部结构**——机载激光是近天底扫描，立面上的点很稀。

3. **规划审批文件理论上精度最高，但对现有球场这条路已经走不通 —— 这是本次调研最重要的否定性结论。** Trafford 的规划台账已通过 **UK PlanIt 聚合 API**（免费、无需密钥）成功取得，**20 条申请编号与官方 `keyVal` 已核实**（见第 2.3 节与 [03-规划图纸与尺寸.md](研究/03-规划图纸与尺寸.md)）。但该地址下的申请**全部是附属设施类**（售货亭、帐篷、雕像、停车场、西南角小扩建），**没有任何一项是看台主体改扩建** —— 1990 年代的大改建早于电子门户上线、从未数字化，1909 年 Leitch 的原申请提交给的是 Stretford 自治市议会。→ **不要再把时间花在找"施工图"上，尺寸缺口须改走实测**（EA LiDAR DSM ±15 cm + 现场激光测距）。唯一值得盯的例外：**New Trafford 新球场**的规划申请，那可能是历史上第一份公开整套球场图纸的文件。

4. **展览级外观只能靠两条路：自采摄影测量，或购买商业模型。** 现成商业模型（TurboSquid / CGTrader / Free3D / Cults3D 均有老特拉福德模型）质量参差、授权各异；自采摄影测量精度最高，但要处理英国无人机法规与球场空域限制。⚠️ **实测结论：老特拉福德处在曼彻斯特机场空域影响范围内；依 NATS 规则，未经 ATC 许可在任何时间飞任何无人机均属违法**（FRZ = 机场 ATZ + RPZ，5 km × 1 km，向上延伸至机场标高以上 2,000 ft，见 `研究/02` E.1）。**比赛日现场航拍基本不可行。**

5. ⚠️ **任务的时间性被改变了：老特拉福德很可能被拆除，这个模型因此从"复制品"变成"档案"。** 新球场（Foster + Partners 设计，10 万座，约 £20 亿）选址已确认为**老特拉福德西北约 350 m** 的铁路货运站地块（2026-07-09 公布），**2026-09-10 Foster + Partners 正式获聘**；老特拉福德预计在新球场建成后被拆除。→ **① 现在能站的机位（Wharfside Way 北侧、运河一侧）未来数年将变成工地；② 展陈叙事应从"这是曼联主场"改为"这是那座已经不在了的老特拉福德"，不可替代性显著提高。** 详见 §2.6 与 [研究/06](研究/06-周边道路与可达性.md) 第 7 节。**不要把这个项目拖到明年。**

6. **法律红线与几何数据同等重要。** 曼联队徽、"Manchester United"、"Old Trafford" 均为注册商标；建筑本身在英国有设计版权（但 CDPA 1988 第 62 条对"拍摄/表现建筑物"有豁免）。**展览（公开展示）与个人学习，法律要求不同**，详见第 4 节与 `研究/04-照片素材与版权.md`。

7. ⭐ **达到"现场测量级"的机位已经找到，而且是官方开放的地面停车场。** 曼联官网 "Getting Here" 页明确：**非比赛日访客被指引使用 E2 停车场**（东看台场，从 **Wharfside Way West** 进，设无障碍车位）。同时官网给出球场免费自行车架位置 **N2 / E2 / W2**，并写明 **N2 = 弗格森看台、E2 = 东看台、W2 = 西看台** —— 这既**证实了四座看台的方位**，也给出了**球场红线内被官方认可的点位**。⚠️ 但官方开放的是"停车"而非"摄影作业"，**架设器材需另行取得书面许可**。详见 [研究/06](研究/06-周边道路与可达性.md) §3。

## 1. 精度分级 × 可行性决策表

| 精度档 | 要表现的内容 | 公开数据能否支撑 | 推荐来源组合 |
|---|---|---|---|
| **L1 体量示意** | 外轮廓、四看台分层、屋面大形、周边环境 | ✅ 可以 | OSM 建筑轮廓 + EA LiDAR DSM 1m + 卫星影像 |
| **L2 展览级外观** | 立面分格、屋面桁架、看台坡度、材质配色 | ⚠️ **部分**：尺度靠公开数据校准，几何靠自采 | EA LiDAR（定标高）+ OS NGD（定footprint/高度）+ 自采摄影测量（定外观）+ 规划图纸（定形制） |
| **L3 结构级** | 桁架节点、悬挑跨度、构件截面尺寸 | ❌ 不可以 | 只能靠规划图纸（若公开）+ 1990 年代工程期刊文献估算 |
| **L4 室内漫游** | 看台内部、走廊、包厢、更衣室 | ❌ 不可以 | 只能自采（球场导览拍摄）或取得官方素材授权 |

**对"展览用 + 较高精度"的直接建议：目标定在 L2。** L2 已经需要自采数据，公开数据在这里的角色是**几何基准与尺度校准**，不是外观来源。

**关键限制（必须理解，否则会误判可行性）：**

- ✅ LiDAR DSM **包含屋顶**，所以老特拉福德的**屋面标高与看台顶部轮廓可以从 1 m DSM 读到**（±15 cm 量级）。
- ❌ LiDAR **不是**扫描式三维重建：机载激光近天底向下打，**立面（竖直面）上的点极少**。四座看台的竖直墙面、悬挑屋盖的下弦、看台内部的阶梯与座席，**都拿不到**。
- ❌ 城市级 LiDAR 不测室内。更衣室、走廊、包厢完全无数据。
- ⚠️ **25 cm / 50 cm 高分辨率档位是否覆盖老特拉福德，必须查索引目录确认**，不能想当然——高分辨率档位通常只针对特定项目区域（如海岸带、洪水区）。核实方法：下载 "Metadata Index Catalogues"（WFS / WMS / GeoPackage / Shapefile 均有），用 OS 网格瓦片号 **SJ 8086 9634** 反查该位置的可用测量年份与分辨率档位。
- ⚠️ 数据下载入口在 **Defra Data Services Platform**（environment.data.gov.uk）。本环境访问该域返回 **HTTP 403（Azure 网关拦截）**，需人工浏览器下载。

### 3.2 本次最重要的三个发现

**① 【突破】规划数据打通了 —— UK PlanIt 聚合 API 是 Trafford 规划门户的替代通道。**

`pa.trafford.gov.uk` 在本环境连接层失败，但 **UK PlanIt**（免费、无需密钥、无需注册）完整镜像了 Trafford 的规划申请台账：

```
https://www.planit.org.uk/api/applics/json?auth=Trafford&lat=53.4631&lng=-2.2913&krad=0.4&pg_sz=60&compress=on
```

返回字段含**真实申请编号、官方 `keyVal`、文档数 `n_documents`、日期、文档页 URL、Planning Portal ID**。
→ 据此已产出**已核实申请编号 / keyVal 对照表**（`研究/03` 第 1.2 节），可直接代入文档页 URL 模板下载附件。
→ 用法坑：`select=` 或 `sort=` 与空间检索同用会报 `{"error": "42703: column record.area_id does not exist"}`，去掉即可 200。

**规划这条路不再是死路。** 但要注意一个重要的**否定性结论**（见 ②）。

**② 【最重要的否定性结论】公开渠道不存在老特拉福德的"施工图级"图纸集 —— 这是可查证的结论，不是检索失败。**

球场地址下的规划申请**全部是附属设施类**：售货亭、帐篷、雕像、停车场、西南角小扩建。**没有任何一项是看台主体改扩建。** 原因清楚：

- 1990 年代的看台大改建**早于电子门户上线**，从未数字化；
- 1909 年 Leitch 的原申请提交给的是 **Stretford 自治市议会**，更早于任何电子系统；
- **唯一涉及看台本体的近期申请是 `81855/FULL/2013`**（西南角象限扩建，含 "minor alterations to the existing elevation"）。

→ **不要再把时间花在找"施工图"上。** 尺寸缺口应改走实测（EA LiDAR DSM ±15 cm + 现场激光测距），详见 `研究/03` 第 5 节。

**③ 【必须先决】照片与版权不是收尾工作，是开工前的前置条件。**

- **三层权利**：① 建筑本体（CDPA 1988 第 62 条豁免，英国法下拍摄不侵权）／② 照片著作权（属摄影师，**第 62 条不覆盖**）／③ **商标**（队徽、"Manchester United"、"Old Trafford"，**CC 授权完全解决不了**）。
- **CC BY-SA 有传染性**：BY-SA 4.0 文本写明 "build upon" —— 照片若作模型贴图/渲染图/展板的一部分，**该衍生作品很可能被要求以 CC BY-SA 发布**。→ **建议方案评审时就定"接受 SA / 不接受（只用 CC0+PD+CC BY+OGL+自采）"**，这直接决定 Commons、Geograph、Mapillary 能否用。
- **中国境内展出是独立风险点**：著作权法**第十条（八）展览权**（模型/展板嵌入他人摄影作品）+ **第五十四条**惩罚性赔偿；**第二十四条（十）"公共场所的艺术作品"是否涵盖建筑作品存在解释空间，不能照搬英国第 62 条**。
- **CDPA 1988 第 62 条本次拿不到逐字原文**（legislation.gov.uk 对该条的 8 次不同形式请求**全部 HTTP 202 + 空正文**）。报告中该条结论基于条目标题与通行理解，**已标注"须律师确认"**。

### 3.3 各专项补充要点

**01 测绘与影像**
- 底图（OSM / OS Open）免费但平面精度有限；OS MasterMap 是平面精度天花板但**付费**。
- 卫星/航空影像几乎全部**禁止生成衍生物**，不能作为建模依据。
- 详见 [01-测绘与影像.md](研究/01-测绘与影像.md)。

**02 点云与三维扫描**
- **EA LiDAR**（免费、OGL、±15 cm RMSE）是本次可得的最高精度公开几何数据。⚠️ **一处关键更正**："城市级 LiDAR 只保留地面点、剔除建筑"这个前提**本身不成立** —— EA 点云只做 **ground / low / medium / high vegetation** 四类自动分类，**分类体系里没有 building 类，也没有剔除建筑回波**；官方 **First Return DSM** 的说明原文写明可用于 **"production of building outlines"**。→ **屋面轮廓与标高能拿到；看台竖直立面、悬挑屋盖下弦、座席阶梯、室内拿不到**（近天底扫描的固有盲区）。
- **授权口径已核实、可以放心**：National LIDAR Programme 与 Composite DSM 1m/2m 的 CKAN 元数据 `extras` 均明确写着 `"licence": ["Open Government Licence"]`；CKAN 页面上显示的 **"No Licence Provided" 只是 `license_id` 字段为空，不是矛盾**。建议把 `package_show` 的返回**存档留痕**，并在展板署名。
- **瓦片命名规则已核实**：官方原文为 **`P_XXXXX_OSOSOS_SDFLOWN_EDFLOWN.*`**（唯一测区 ID + OS 格网参考 + 首末测量日期），**不要照抄臆测的文件名**，实际名称以索引目录为准。
- **现成模型有便宜的合法选项**：Sketchfab 上 **asensio 版（144,511 面）为 CC BY —— 可商用、可公开展示，只需署名**。⚠️ **RenderHub 版 $59.99（439,835 面，面数最高）授权是 Extended Use License (IP Restricted) + Editorial Use Only —— 公开展览属高风险用途，买前必须逐一确认。**
- **比赛日禁飞有法律依据**：英国曾**为老特拉福德单独发布飞行限制法规** —— **UKSI 2019/635《The Air Navigation (Restriction of Flying) (Old Trafford, Manchester) Regulations 2019》**（BAILII 标题已实测；正文未读到）。
- **自采合规**：球场距曼彻斯特机场约 **12 km**，**很可能不在永久 FRZ 内**，但"很可能"≠"可以飞"。NATS 规定 FRZ = 机场 ATZ + RPZ（5 km × 1 km，自跑道 threshold 起算），**向上延伸至机场标高以上 2,000 ft**；**未经 ATC 许可在任何时间飞任何无人机均属违法**。CAA 另有"**不得飞越人群**、开放类 **≤120 m**"。→ 每次起飞前必须完成三件事：**查 UK AIP ENR 5.1 + 当日 PIB 简报 + 取得俱乐部与土地所有者书面许可**。
- ⭐ **推荐路线：地面摄影测量**（公众道路/人行道可达视点，**不涉及空域**，精度 **5–20 mm**，足以支撑展览），**用 EA LiDAR 的屋面标高做全局基准**约束绝对尺度与位置（`DSM − DTM` = 屋面相对高度，最实用的免费技巧）。无人机只在拿到三方许可后作为屋盖顶面的补充。
- **Global 3D Tiles / Google Photorealistic 3D Tiles（25 cm 真正射）** 看起来够用，**但条款明确禁止生成衍生物**（已取得微软官方答复原文）。
- **商业替代入口**：**Bluesky MapShop** —— **唯一可自助在线下单**的商业 LiDAR（DSM 50 cm/1 m/2 m，**XY ±10 cm / Z ±5 cm RMSE**）；其 MetroVista Mesh 覆盖名单**明确含 Manchester**（但是否含 Trafford 未声明）。另有 **OS 3D Mesh (Beta)**（15 cm 摄影测量实景三维，含建筑体块与纹理）。
- 详见 [02-点云与三维扫描.md](研究/02-点云与三维扫描.md)。

**03 规划图纸与尺寸**
- **看台名称沿革**（做展签必用，也最容易错）：北 = Sir Alex Ferguson Stand（旧 North Stand）；南 = Sir Bobby Charlton Stand（旧 South Stand）；西 = Stretford End；东 = East Stand（**旧称 Scoreboard End**）。
- **容量有三个冲突口径**：74,197 / 74,244 / 74,310。**建议以英超官方口径 + SEC 20-F 年报为准，并注明统计年份。**
- **官方口径的竖向尺度锚点**：球场导览路线 **177 级台阶**（俱乐部官方 FAQ 原文）。
- **唯一可查到的结构级数字**：1996 年 North Stand 悬挑屋盖自后墙至看台前缘伸出 **58.5 m**（来源 StadiumDB，**D 级，未经工程文献交叉验证**）。
- **1909 年 Leitch 方案的"南看台立面图"被记载为存世**（原文用 "surviving elevational drawings of the south stand"），**但未说明现存何处** —— 这是本项目最值得追的一条历史线索。线索指向：俱乐部博物馆 `museum.enquiries@manutd.co.uk`、Trafford Local Studies 付费研究服务、RIBA 档案馆。
- **信息申请走 EIR 2004 而非 FOIA 2000**（球场规划/环境类信息适用环境信息法规，门槛更低、时限更短）。

**04 照片素材与版权**
- **本机网络有一条清晰分界线**：法条/许可文本/机构官网 ✅ 读到正文（CC 三种许可文本、OGL v3.0 全文、CAA 规则、manutd.com 条款、中国人大网《著作权法》全文、Trafford Local Studies 版权页、NCAP）；而 **Commons / Wikipedia / Google / YouTube / Getty / Shutterstock 全部 fetch failed，Geograph / UKIPO 商标库 / Alamy / Historic England 全部 403**。
- → 素材清点这一半**只能换网络做**。交付的是**真实链接 + 逐条访问状态 + 可执行的检索方法**（Flickr 的 "Commercial use allowed" 过滤器、Geograph 网格号 `SJ8095`），**不是编造的数量与分辨率**。
- **规划图纸不在 OGL 覆盖内**（由申请人/建筑师提交，属第三方作品），与 `研究/03` 结论一致。
- 详见 [04-照片素材与版权.md](研究/04-照片素材与版权.md)。

## 6. 建议的执行路径（按优先级）

1. **先人工开浏览器，拿下 Trafford 规划门户的场地档案页**（第 2.3 节的第一个链接）。这是公开渠道里**唯一可能含有精确立面/剖面图**的地方，价值最高，成本最低。
2. **注册 OS Data Hub 免费账号**，下载老特拉福德范围的建筑轮廓与高度数据，建立平面基准。
3. **下载 EA LiDAR**（环境署平台）：先取 **Composite DSM 1m** 与 **FZ_DSM 1m** 的 SJ 瓦片，得到屋面标高；再查索引目录确认是否有 25/50 cm 档；如需点云再下 **Time Stamped Point Cloud**。
4. **核对授权**：LiDAR 的 CKAN 元数据标 "No Licence Provided"，与"政府开放数据默认 OGL"的假设冲突，**必须向 Defra/环境署确认可用于公开展览**。
5. **决定外观来源**：自采摄影测量（精度最高，需处理无人机法规与球场空域）或购买商业模型（快，但需看授权）。
6. **法律前置**：队徽与商标、建筑版权、照片授权三件事，在建模**之前**定方案，否则后期返工成本极高。
